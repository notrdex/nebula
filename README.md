# Nebula Docker Panel

A lightweight Pterodactyl/Nebula-inspired panel for managing Docker containers as "VMs".

## Important Render limitation

The panel can be deployed as a Render web service, but a normal Render web service is **not a Docker host**. The `DOCKER_HOST` setting must point to a Docker daemon that you control and that permits remote API access. Without that, the dashboard/login works but "Create Docker VM" cannot actually create a container.

The panel enforces the configured resource pool at the application level and Docker enforces RAM/CPU. `POOL_STORAGE_GB` is a tracked allocation value; a true hard per-container disk quota depends on the Docker host/storage driver and is not guaranteed by this starter project.

## Default login

Username: `admin`

Password: set `ADMIN_PASS` in Render. Do not leave a weak/default password on a public deployment.

## Render variables

- ADMIN_USER=admin
- ADMIN_PASS=your-strong-password
- SECRET_KEY=generated by Render
- MAX_VMS=3
- POOL_RAM_MB=32768
- POOL_CPU=8
- POOL_STORAGE_GB=100
- CONTAINER_IMAGE=ubuntu:24.04
- DOCKER_HOST=<your reachable Docker daemon>

This project is intended as a starter implementation, not a production-grade multi-tenant virtualization platform.
